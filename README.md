# AP Public School - Smart Attendance System

A complete Flutter attendance solution for AP Public Higher Secondary from Prep to Class 10.

### 📱 Live APK Features (From Your Video)
- Dashboard: Present 11, Absent 5, Total 25, 65% Attendance
- Alert: 2 students need attention (<75%)
- Class Progress: Prep to Class 10
- Smart Alerts: Repeated Absence with % (inshra 0%, Danish Farhan 62%)
- Direct Guardian Calling
- Attendance Entry: P / A / L / E with Mark All Present
- Roster: 25 Students with Guardian name & contact, Search, Add Student with Photo
- Admin: Section Management, Role-Based Access, PIN Lock 1234, Dark Mode, Excel & JSON Backup, Holiday Calendar

### 🛠️ Tech Stack
Flutter, Dart, Hive Local Database

### 🚀 How to Run
flutter pub get
flutter run
